# REA Group / PropTrack

> REA Group Limited (ASX:REA) operates realestate.com.au, realcommercial.com.au and
> the property data brand PropTrack. Its public API surface is the PropTrack
> Property Data APIs — nine OpenAPI 3.1 services, 32 operations, covering address
> matching, property attributes and history, listings, sold transactions, automated
> valuations (AVM), PDF reports and suburb-level market analytics for Australia.
> Access is partner-gated (OAuth 2.0 client credentials under a commercial
> agreement), but every service publishes a live, unauthenticated mock server.

## Getting started

- [Developer portal](https://developer.proptrack.com.au/): PropTrack API documentation home
- [How to authenticate](https://developer.proptrack.com.au/docs/apis/how-to-authenticate): OAuth 2.0 client credentials, Basic-authenticated token request, 1-hour JWT
- [API guide](https://developer.proptrack.com.au/docs/apis/guide): the full API reference
- [API trials](https://developer.proptrack.com.au/docs/apis/api-trials): quota, expiry and trial data restrictions
- [Terms of use](https://developer.proptrack.com.au/docs/apis/terms-of-use): PropTrack Trial & Evaluation License Terms
- [Contact sales](https://www.proptrack.com.au/contact-us): the only route to credentials — there is no self-serve signup

## APIs

- [OAuth 2.0 Token API](https://developer.proptrack.com.au/docs/apis/how-to-authenticate): POST /oauth2/token, client credentials to JWT bearer
- [Address API](https://developer.proptrack.com.au/docs/apis/address): match and suggest — resolve free-text addresses to propertyId
- [Properties API](https://developer.proptrack.com.au/docs/apis/properties): summary, attributes, listings, transactions, planning, tenure, search, and the AVM valuation surface
- [Listings API](https://developer.proptrack.com.au/docs/apis/listings): listing by id, point-and-radius and suburb-and-postcode search
- [Transactions API](https://developer.proptrack.com.au/docs/apis/transactions): sold transaction search by geography
- [Market API](https://developer.proptrack.com.au/docs/apis/market): sale and rent history, supply and demand, auctions, demographics
- [Reports API](https://developer.proptrack.com.au/docs/apis/reports): AVM PDF report and property report
- [Disclaimers API](https://developer.proptrack.com.au/docs/apis/disclaimersbranding): the attribution text PropTrack requires alongside its data
- [Upcoming APIs](https://developer.proptrack.com.au/docs/apis/coming-soon): nearby education facilities, documented ahead of release

## Operating rules

- [Authentication profile](https://raw.githubusercontent.com/api-evangelist/rea-group/refs/heads/main/authentication/rea-group-authentication.yml): OAuth 2.0 client credentials, tokenUrl https://data.proptrack.com/oauth2/token, 3600s JWT
- [API conventions](https://raw.githubusercontent.com/api-evangelist/rea-group/refs/heads/main/conventions/rea-group-conventions.yml): cursor pagination, error envelope, X-Transaction-Id tracing, no idempotency
- [Error codes](https://raw.githubusercontent.com/api-evangelist/rea-group/refs/heads/main/errors/rea-group-error-codes.yml): 18 codes — 7xxx validation, 9xxx platform
- [Rate limits](https://raw.githubusercontent.com/api-evangelist/rea-group/refs/heads/main/rate-limits/rea-group-rate-limits.yml): 50 rps reads, 25 rps valuations and reports, rolling one-second window
